Volta Engine
Serverless runtime · sub-100ms cold starts

A serverless microVM runtime using Linux userfaultfd for lazy memory restoration. Snapshots VM state and resumes on-demand — booting the VM before full memory is copied, achieving sub-200ms cold starts.

  • KVM microVMs — Firecracker-based VM isolation on Linux for strong security boundaries and minimal overhead.
  • UFFD lazy restore — Memory loaded on-demand via userfaultfd; VM boots before full memory copy completes.
  • Snapshot / Restore — Capture and resume VM state at any checkpoint; enables near-instant scale-out from warm snapshots.
  • Python SDK — Thin async client over HTTP API (spawn, resume, snapshot) with a daemon (voltad) managing the VM lifecycle.
